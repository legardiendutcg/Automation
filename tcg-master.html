Connexion requise

Connecte-toi avec le compte Google master pour piloter la synchronisation. Tant que la connexion n'est pas établie, le reste de l'interface est inactif.

⛔ Accès refusé

Ce compte Google n'est pas autorisé à utiliser l'app master.

—

Si tu es vendeur, utilise plutôt l'app TCG Sales. Pour ajouter ce compte, modifie la constante MASTER_EMAILS en haut du fichier.

Session active ailleurs

Une session master est déjà active sur un autre appareil. Cette instance reste en lecture seule pour éviter deux masters simultanés.

🏖️ Event activé — canaux parallèles
À faire AVANT de rafraîchir le stock

Pendant l'event, tu ne pourras pas surveiller tes canaux de vente en ligne. Effectue ces 3 étapes dans l'ordre :

  1. Mettre en pause les canaux de vente parallèles :
    CardMarket → Menu compte → Mode vacances : ON
    Vinted · Whatnot · Facebook (à venir)
  2. Reporter dans la GSheet les dernières ventes CM non encore enregistrées.
  3. Rafraîchir le cache Master (bouton 🔄) pour publier le stock à jour.
🔔 Event clôturé — pense à réactiver
Tes canaux en ligne sont toujours en pause

L'event est archivé. Pense à sortir du mode vacances sur tes canaux de vente :

  • CardMarket → Menu compte → Mode vacances : OFF
  • Vinted · Whatnot · Facebook (à venir)
